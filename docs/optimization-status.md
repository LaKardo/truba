# Оптимизация: реализация и проверка

## Выполнено

- `status(cached=true)` повторно использует снимок stats; CLI и API без параметра читают актуальные счётчики.
- Шесть чтений наборов устройств выполняются через один shell вместо шести; отдельные процессы nft сохранены из-за поведения nft 1.1.6.
- `status(part=dns|rules)` не запускает ненужные этим вкладкам команды nft, awg и ip.
- `devices(lite=true)` передаёт последнюю минуту вместо часовой истории.
- Политики устройств, интерфейсы LAN и geoip обновляются одной транзакцией nft без пересоздания таблицы при неизменной структуре правил. Изменение geosite очищает DNS-наборы точечно. Копия last-good учитывает изменение элементов.
- `ip rule` читается один раз; корректные правила сохраняются, дубли и отличающиеся правила исправляются.
- Hotplug повторно использует загруженную конфигурацию и применённый IP того же endpoint.
- Зоны firewall читаются одним проходом, состояния повторяющихся сетей переиспользуются.
- Вложенность geosite вычисляется через обратный индекс и наиболее редкую запись.
- Межфайловое копирование использует блоки 64 КиБ вместо чтения всего файла в память.
- DNS-подсказки кэшируются с исходным сроком DNS-ответа, ограничением 30 с и проверкой процесса mosdns.
- Размеры DNS-наборов кэшируются на 30 с по поколению nft.
- Скрытые вкладки приостанавливают опрос; uPlot загружается только на вкладках с графиками.
- uPlot заменён официальной минифицированной сборкой с ES-экспортом: 145423 → 51104 байт (−64,9%). Преобразование воспроизводится `tests/luci/vendor.mjs`, итоговая сумма закреплена в VERSIONS.
- Поисковые строки категорий переиспользуются через WeakMap.
- Карточка категорий мемоизирована по данным и объекту изменений UCI; список устройств использует общий индекс MAC при фильтрации, сортировке и отрисовке строк.
- Массивы графика скорости пересчитываются только при изменении истории, времени или выбранного периода.
- Журнал читается потоково с ограниченным кольцевым буфером, без процессов grep и tail.
- Router-части CI используют общий кэш Docker; версии образов вынесены в `tests/images.env`.
- Зависимости VPS-тестов (включая sshd, GnuPG и unbound) включены в подготовленный образ.
- Для SDK добавлены кэш загрузок, фидов и ccache; для сборки и скачивания — таймауты.
- Три фиксированных ожидания браузерных тестов заменены ожиданием сообщения в DOM.
- Установщик повторно использует индексы apt до изменения источников.

- Geoip в last-good хранится отдельно: `geoip-<key>.nft` подключается из `truba.nft`. Смена Политики не переписывает крупные CIDR-данные. Новый файл записывается до переключения ссылки; прежний удаляется после неё. Проверены сохранение inode, `nft -c` и восстановление при ошибке применения.

## Оставшиеся работы

- Ожидания UI: фиксированные паузы остаются только там, где тест проверяет отсутствие изменения за окно времени (нажатие на уже выбранный Режим, неверный ввод MTU не пишется, выключенное «Следить» без опроса 12 с, `dz` в одном evaluate) и в циклах опроса состояния службы. Ожидания появления состояния заменены на `waitForFunction`; фокус после удаления строки ждётся отдельно — приложение переносит его на следующем кадре.
- Измерения CPU, пиковой памяти и задержек до/после на целевом роутере.
- Проверка SDK-сборки в CI: локальный `gh auth status` сообщает об отсутствии авторизации GitHub; результат сборки пока не подтверждён.

## Решения по первоначальным предложениям

Для сравнения задержек и размера ответов: `sh tests/benchmark-router.sh 10 2>&1` на одном и том же Роутере до и после обновления. CPU/RSS в выводе относятся к клиенту ubus, не к rpcd; для нагрузки службы нужны отдельные системные измерения.

- Полный набор проверок перед публикацией сохранён: результат PR не обязательно относится к итоговому коммиту.
- Фоновая статистика не зависит от открытых вкладок: это нарушило бы непрерывность истории.
- Дальнейшее объединение nft-вызовов отклонено для текущей схемы: [ADR 0018](adr/0018-device-traffic-in-ram.md) фиксирует потерю результатов при нескольких `list set` и стоимость `list table` с geoip (330 мс против 3 мс на набор на x86). Шесть наборов читаются отдельными nft-процессами через общий shell; изменение схемы статистики выходит за рамки оптимизации без изменения сетевой семантики.
- Дробный `sleep` в тестах роутера не используется: BusyBox стенда его не поддерживает.
- `daemon-reload` при перезапуске SSH выполняется только при включённом ssh.socket (генератор портов). При изменении разных юнитов вызовы сохранены: между ними выполняются операции systemd и транзакционная проверка SSH.
- Прохождение тестов означает проверку сценариев, а не измеренное ускорение. Непроверенные изменения CI не считаются подтверждённой сборкой SDK.

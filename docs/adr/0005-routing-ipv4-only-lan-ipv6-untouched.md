# Маршрутизация только по IPv4, IPv6 домашней сети не трогаем

- Статус: принято
- Дата: 2026-10-04

Сначала IPv6 в домашней сети планировалось выключить, чтобы трафик не утекал мимо Маршрутизации. Но IPv6 нужен mesh-системе roamd (Ground-Zerro/roamd): контроллер на Роутере ищет узлы через IPv6 link-local (`ff02::1` на `br-lan`). Полная поддержка IPv6 в Маршрутизации (IPv6-наборы geoip, IPv6 на Трубе, NAT66 или выделенная подсеть /64) отложена как отдельное расширение. Поэтому Маршрутизация, перехват DNS и метки работают только с IPv4. IPv6-настройки домашней сети (RA, DHCPv6, ULA, `ip6assign`) Труба не меняет. Выход устройств в интернет по IPv6 закрыт правилом межсетевого экрана `lan → wan`, IPv6, REJECT.

## Последствия

- Провайдер IPv6 не выдаёт, поэтому правило сейчас — страховка: если IPv6 у провайдера появится, трафик не уйдёт мимо Туннеля незаметно.
- mosdns по-прежнему отдаёт пустой ответ на AAAA-запросы интернет-доменов. Локальные имена отвечает dnsmasq, не пересылая их в mosdns. roamd работает по адресам, а не по именам, поэтому исключения ему не нужны.

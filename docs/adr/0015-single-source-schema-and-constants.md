# Один источник значений: схема настроек и константы службы

- Статус: принято, 2026-10-12

## Контекст

Значения по умолчанию, пределы настроек, пути и имена записывались заново в каждой части, которой они нужны. Аудит 2026-10-12:

- **Умолчания и пределы настроек** — в `conf.uc`, в `/etc/config/truba`, в полях LuCI (подсказки, `datatype`, `default`) и в shell-скриптах. Имя интерфейса Туннеля записано в шести местах, зона `lan` — в четырёх, DNS-серверы по умолчанию — в трёх, схемы адресов DNS — в двух (их сверял отдельный тест).
- **Пути** — в `const.uc` и заново строками в rpcd-плагине, `core.uc`, `net.uc`, init-скрипте, hotplug и `uninstall.sh`.
- **Параметры службы для интерфейса** — сроки истории скорости и окно проверок watchdog есть и в службе, и копиями в LuCI; имя зоны `truba` — строкой в трёх представлениях.
- **Копии уже разошлись.** Вкладка «Туннель» красила возраст рукопожатия по жёстким 180 и 300 с, а watchdog судит по настраиваемому `handshake_max`. При `handshake_max 600` вкладка показывала ошибку там, где watchdog считал Туннель живым.

## Рассмотренные варианты

- **По одному месту на слой и тест на совпадение**: константы в ucode, объект умолчаний в `common.js`, общий shell-файл; юнит-тест сверяет копии. Изменений меньше, но у каждого значения остаются три копии, и тест должен знать о каждой новой. Отклонено.
- **Только ucode и найденная ошибка.** LuCI и shell по-прежнему повторяют умолчания `conf.uc` — а копии разошлись именно там. Отклонено.
- **Сократить `/etc/config/truba` до секций**, чтобы не осталось ни одной копии. На чистой установке `uci show truba` почти пуст, пока владелец не сохранит страницу LuCI, и настройки не видно из консоли. Отклонено: файл остаётся полным образцом под контролем теста.

## Решение

Значения живут в ucode службы, остальные части берут их у неё.

- **Схема настроек** — `SCHEMA` в `conf.uc`: тип каждой опции UCI, значение по умолчанию, пределы или шаблон. `load()` берёт умолчания и пределы только из неё; структура `cfg` не меняется.
- **Константы** — в `const.uc`, пути выводятся из каталогов. Туда же переезжают сроки истории скорости и окно проверок watchdog — они нужны и службе, и интерфейсу. Адрес mosdns (`127.0.0.1`), записанный в семи местах, тоже становится константой.
- **LuCI** при загрузке страницы получает схему и константы вызовом `truba.schema` (команда `truba schema`): подсказки, проверки и значения по умолчанию полей, действующие значения опций, имя зоны Туннеля, окно проверок, сроки истории. Живые параметры — из итогов службы: `health.json` несёт `handshake_max`, и «Туннель» красит рукопожатие по нему и по вердикту watchdog.
- **rpcd-плагин** импортирует `truba.const` и `truba.util`: пути итогов и команда службы — оттуда.
- **Shell** получает значения командой `truba env` — присваивания `TRUBA_*`; `TRUBA_IFACE` — действующее имя интерфейса после проверки `conf.uc`, а не сырое значение UCI. Её используют init-скрипт, uci-defaults и `uninstall.sh`. Hotplug целиком переходит в `truba hotplug`.
- **Исключение — `reinstall.sh`.** Он работает после sysupgrade, когда пакета ещё нет и спросить не у кого. Путь бэкапа dnsmasq и порт mosdns по умолчанию в нём — литералы; юнит-тест сверяет их со службой.
- **`/etc/config/truba`** остаётся полным образцом настроек; юнит-тест сверяет его со схемой в обе стороны.
- **Числа без имени** получают имя и объяснение. Протокольные значения — порт 53, `224.0.0.0/4`, маска `255.255.255.255` — остаются в коде.

## Последствия

- Значение по умолчанию или предел меняются в одном месте — в схеме; LuCI и shell подхватывают их без правок. Новая опция — строка в схеме и в `/etc/config/truba`, и про второе напомнит тест.
- Страница LuCI при загрузке делает ещё один вызов rpcd — один запуск `truba schema`.
- Shell-скрипты пакета не работают без `/usr/sbin/truba`: `truba env` — их единственный источник путей. Для init-скрипта, uci-defaults и `uninstall.sh` это так и есть, они часть пакета. Поэтому `reinstall.sh`, который работает без пакета, остаётся автономным.
- Проверка схем DNS в `static.mjs` больше не нужна, копии нет. Вместо неё — проверка, что в представлениях LuCI нет числовых подсказок, `range(…)` и имён `awg0`, `lan`, `truba` в роли значений.
- Правило `truba_no_ipv6_inet` (`lan → wan`) осталось прежним: распространить его на все зоны Маршрутизации — отдельное решение (ADR 0016).

## Пересмотреть, если

- интерфейсу понадобится работать без службы — тогда схема должна приезжать в пакете LuCI;
- shell-скриптам понадобятся значения там, где `truba` ещё нет (как `reinstall.sh`), — тогда нужен общий файл констант, который сборка порождает из `const.uc`.

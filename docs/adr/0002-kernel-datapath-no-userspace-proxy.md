# Трафик Туннеля идёт через ядро, а не через программный прокси

Привычный для `.dat`-файлов путь — Xray, sing-box или mihomo в режиме TPROXY/TUN. Но тогда соединения в Туннель открывает сам прокси, и ни FullCone NAT ImmortalWrt, ни проброс портов к устройствам домашней сети на этот трафик не действуют. Поэтому трафик Туннеля идёт через ядро: метки пакетов (fwmark), отдельная таблица маршрутизации и наборы адресов nftables. Наборы правил только сортируют трафик: geoip превращается в набор подсетей, а для geosite DNS-резолвер кладёт полученные IP в наборы nftables.

## Последствия

- Правила по доменам работают только для устройств, которые резолвят имена через Роутер. Шифрованный DNS в браузере (DoH) их обходит; в Режиме «Всё в туннель» это безопасно — такой трафик просто уйдёт в Туннель.
- Если один IP обслуживает домены с разными Действиями (общий CDN), разделить их нельзя: решает фиксированный порядок проверки наборов адресов, а не домен. Это ограничение маршрутизации по IP. Домены «По режиму» в наборы не попадают вовсе, а IP из DNS действуют ограниченный срок (ADR 0007).

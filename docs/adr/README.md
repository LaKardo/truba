## Как вести

- Один файл — одно решение: `NNNN-короткое-имя.md`, следующий свободный номер.
- Разделы: «Контекст», «Рассмотренные варианты» (если выбирали), «Решение», «Последствия», «Пересмотреть, если». Последний раздел — условия, при которых решение перестаёт быть верным: с него начинают, когда что-то в системе меняется.
- Вверху — статус: «предложено», «принято» или «заменено ADR NNNN». Новые ADR — с датой.
- Решение изменилось — пишется новый ADR со ссылкой на прежний, у прежнего статус меняется на «заменено». Уточнения, которые решения не меняют, вносятся на месте.
- Код ссылается на ADR по номеру («ADR 0006»), поэтому номера не переиспользуются.

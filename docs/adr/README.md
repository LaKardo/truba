# Решения (ADR)

Каждое значимое решение — отдельный файл: контекст, рассмотренные варианты, решение и последствия, вверху — статус и дата. Принятый ADR задним числом не переписывается. Если решение изменилось, пишется новый ADR со ссылкой на прежний, а у прежнего статус меняется на «заменено ADR NNNN». Уточнения, которые решения не меняют (например, ссылка на более поздний ADR в последствиях), вносятся на месте.

Как устроена система — в [docs/architecture.md](../architecture.md), термины — в [CONTEXT.md](../../CONTEXT.md).

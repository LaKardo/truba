# Домашний шлюз через собственный VPS

Домашняя сеть выходит в интернет через собственный VPS по туннелю AmneziaWG; VPS отдаёт роутеру свой публичный IP целиком, а роутер решает, какой трафик пустить через туннель, а какой напрямую.

## Узлы

**Труба**:
VPS, который не принимает решений о трафике: всё, что приходит на его публичный IP (кроме Служебных портов), отдаёт Роутеру, а исходящий трафик Роутера выпускает от своего IP. Обслуживает только Роутер, других клиентов у неё нет.
_Avoid_: сервер, VPN-сервер, прокси

**Роутер**:
Домашний роутер на ImmortalWrt; единственное место, где принимаются решения о маршрутизации и где выполняется Full cone NAT.
_Avoid_: клиент, шлюз

**Туннель**:
Единственный канал AmneziaWG между Трубой и Роутером.
_Avoid_: VPN, соединение

**Служебные порты**:
Порты публичного IP Трубы, которые остаются за самой Трубой и не пробрасываются Роутеру (управление VPS и приём Туннеля).

## Трансляция адресов

**Full cone NAT**:
Поведение NAT, при котором однажды открытое внешнее отображение адрес:порт принимает входящие пакеты от любого внешнего узла; в этой системе его обеспечивает только Роутер.
_Avoid_: открытый NAT, NAT type A

## Правила маршрутизации

**Набор правил**:
Один из двух исходных файлов — `geoip.dat` (kirilllavrov/geoip-builder) или `geosite.dat` (kirilllavrov/geosite-builder) — используемый без изменений.
_Avoid_: список, база, ruleset

**Категория**:
Тег внутри Набора правил в том виде, в каком он есть в файле (например `category-ru` в geosite, `ru` в geoip). Используется только целиком: новые Категории не создаются, атрибуты (`@cn`, `@ads`) не применяются.
_Avoid_: группа, список, `geosite:ru` (такого тега нет)

**Действие**:
То, что Роутер делает с трафиком Категории: «По режиму», «Напрямую», «Туннель» или «Блок».

**Напрямую**:
Через провайдера Роутера, минуя Туннель.
_Avoid_: direct, WAN, локально

**Режим**:
Действие для трафика, которому не назначено явное Действие ни одной Категорией: «Всё в туннель» (по умолчанию Туннель, российское — Напрямую) или «Выборочный» (по умолчанию Напрямую, в Туннель — только выбранные Категории).
_Avoid_: режим A/B, белый/чёрный список

**Приоритет**:
Порядок, в котором разрешается конфликт Действий для одного адреса: Блок → Категория geosite → Категория geoip → Режим. Из пересекающихся Категорий geosite побеждает более узкая (вложенная, иначе — с меньшим числом записей); при равенстве — Блок → Туннель → Напрямую. Если IP попал под домены Категорий с разными Действиями, Туннель побеждает Напрямую. Домены без явного Действия («По режиму») в наборы адресов не попадают, поэтому их адрес, общий с доменом «Напрямую», идёт Напрямую; IP из DNS действуют ограниченный срок, по умолчанию сутки (ADR 0007).

**Стартовые настройки**:
Действия Категорий, которые выставляются при установке и по кнопке сброса; у каждого Режима свои.
_Avoid_: пресет, шаблон, дефолты

**Политика устройства**:
Исключение для конкретного устройства домашней сети: «Всё в туннель», «Всё напрямую» или «По правилам» (общие Режим и Действия).
_Avoid_: профиль, правило клиента

**Маршрутизация**:
Совокупность всех правил Роутера, которые распределяют IPv4-трафик домашней сети по Действиям; включается отдельно от Туннеля. IPv6 домашней сети она не касается. Когда она выключена, всё идёт Напрямую, но входящие через IP Трубы продолжают работать.
_Avoid_: «VPN включён», режим работы

**Аварийная блокировка**:
Поведение при неработающем Туннеле, когда трафик с Действием «Туннель» отбрасывается, а не уходит Напрямую; включается переключателем, по умолчанию включена.
_Avoid_: kill switch, failover
